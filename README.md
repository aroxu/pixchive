# Pixchive

Pixchive는 Pixiv 북마크 작품을 로컬 원본·메타데이터·태그와 함께 보관하는 셀프호스팅 아카이브입니다.

## GHCR로 실행

GitHub Actions는 main의 변경을 검증한 뒤 `ghcr.io/aroxu/pixchive:latest`와
`sha-<전체 커밋 SHA>` 태그를 게시합니다. 현재 대상은 `linux/amd64`입니다.
web과 worker는 같은 이미지를 사용합니다.

새 설치에서 `.env.example`을 `.env`로 복사한 뒤
`PIXCHIVE_IMAGE=ghcr.io/aroxu/pixchive:latest`와 실제 접속 Origin을 지정하세요.
패키지가 비공개라면 먼저 `docker login ghcr.io`로 인증합니다.

```sh
mkdir -p secrets
docker compose pull
docker compose -f docker-compose.yml -f compose.init.yml run --rm --no-deps --no-build web python -m app.cli init
docker compose up -d --no-build
```

직접 빌드와 로컬 실행은 [실행 안내](docs/README.md), 기존 환경의 업데이트는
[운영 안내](docs/operations.md)를 따릅니다. 이미 사용 중인 `.env`·키·데이터는
덮어쓰지 마세요. 사용자 보관 자료와 인증 정보는 저장소·이미지에 포함하지 않습니다.

## 구현 범위

현재 개발 단계에서 다음을 사용할 수 있습니다.

- React 19 + Vite + HeroUI v3 기반의 한국어 라이브러리, 상세, 작가, 태그, 작업, 설정 화면
- FastAPI + SQLite WAL + Peewee 명시적 초기 마이그레이션
- 관리자 세션·CSRF·Origin 검증과 암호화된 Pixiv PHPSESSID 쿠키 보관
- ID 기반 원본 저장, Pillow 검증, 원자적 파일 이동, 인증된 미디어 제공
- Redis outbox와 독립 arq worker의 작업 lease·heartbeat·재시작 복구 기반
- 일반 동기화(새 작품·바뀐 작품·오래된 정보만 상세 확인)와 전체 메타데이터 갱신, DB 기반 예약 실행
